LEVEE 已部署。{{ if eq .Values.mode "single" }}（单机模式：SQLite 存储）{{ else }}（集群模式：{{ .Values.cluster.workers }} 个 worker + 1 个 master，共享 PostgreSQL）{{ end }}

1. 核对健康状态与版本：

   kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "levee.fullname" . }} {{ .Values.service.httpPort }}:{{ .Values.service.httpPort }}
   # 浏览器打开 http://127.0.0.1:{{ .Values.service.httpPort }} （Web UI）
   curl -s http://127.0.0.1:{{ .Values.service.httpPort }}/healthz      # {"status":"ok"}

2. 取认证令牌（若用 existingSecret 则按你们自己的 Secret 取）：

   kubectl -n {{ .Release.Namespace }} get secret {{ include "levee.secretName" . }} -o jsonpath='{.data.named-token-0}' | base64 -d

3. 首次使用（本机装好 CLI，或进容器执行）：

   levee -c /etc/levee/config.yaml doctor                # 环境自检
   levee template create --name <name> --content '...'   # 建模板
   levee target import <hosts.yaml>                      # 登记目标机（引擎执行的前提）
   # 然后：new → approve → apply，全程审计留痕
