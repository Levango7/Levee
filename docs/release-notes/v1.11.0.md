# v1.11.0 Release Notes

**Release Date**: 2026-08-27

## Overview

This release ships the accumulated security hardening, bug fixes, and Web UI
contract alignment that landed after v1.10.0. It also adds the Apache-2.0
LICENSE file and a vet/gofmt cleanup pass.

## Security Hardening

- **P0 gateway wiring fix**: `levee serve` now starts the configured service
  instance instead of an empty REST gateway. `/healthz` returns 503 until
  service registration completes.
- user module arguments uniformly quoted to prevent parameter injection
- WinRM channel PowerShell path escaping fix
- SSH host-key verification enabled by default (strict-by-default)
- Approval/archive state-machine guards: reject illegal transitions with audit
- WORM cascade-delete protection: `PRAGMA recursive_triggers=ON`
- [SA-004] SecureZero adds `runtime.KeepAlive` to prevent compiler optimization
- [SA-005] argon2id memory cost raised to 194 MiB (OWASP 2024)
- [SA-006] Permission matrix guarded by `sync.RWMutex`
- [SA-007] Permission denial auto-records audit trace
- [SA-008] Hash-chain ordering uses secondary sort key for determinism

## Bug Fixes

- macOS/BSD plugin sandbox build fix (unix build constraints)
- List pagination `offset` parameter now effective (SQLite / PostgreSQL)

## Web UI

- Frontend-backend API contract alignment; new login page

## Documentation

- CLI docs aligned with implementation (new/clone/push/drift/agent/serve)

## Engineering

- vet/gofmt cleanup: IPv6-safe `net.JoinHostPort` in `cmd_serve.go`
- Added Apache-2.0 LICENSE file
