# v1.9.0 Release Notes

**Release Date**: 2026-08-18

## Overview

Phase D (高级诊断) of the OpsMesh integration is now complete. This release adds advanced diagnostic capabilities including distributed topology analysis, additional alert adapters, LLM-based conversational diagnosis, RAG knowledge augmentation, and fix outcome learning.

## New Features

### D1: SkyWalking/Pinpoint Topology Analysis
- Unified `Collector` interface for distributed topology collection
- SkyWalking GraphQL API client
- Pinpoint REST API client
- Normalized `Topology`/`Node`/`Edge` graph model

### D2: Zabbix/Nagios Alert Adapters
- Zabbix webhook adapter (JSON payload, array support)
- Nagios HTTP webhook adapter (JSON payload, array support)
- Sentinel errors `ErrInvalidPayload` / `ErrMissingField`

### D3: LLM Conversational Diagnosis
- Multi-turn reasoning engine with convergence detection
- Reasoning context management (Turn, Status, Hypothesis)
- Configurable max turns and convergence threshold

### D4: RAG Knowledge Augmentation
- Embedding provider interface with deterministic mock implementation
- In-memory vector store with cosine similarity
- RAG retriever with prompt augmentation pipeline

### D5: Fix Outcome Learning
- Feedback learner with Record/Learn/RecordAndLearn APIs
- Automatic FixPattern creation from successful outcomes
- Statistics tracking (success rate, pattern stats)
- Thread-safe concurrent access
