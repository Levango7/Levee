## Behaviour changes (read first)

- **清单写入会拒绝 env 冲突**。`target-ownership.yaml` 声明过的主机，若 `AddTarget` 或 `ImportTargets` 会把 `labels.env` 写成另一个值，默认 `FailedPrecondition`（REST 412）。批量同步需显式 `allow_env_conflict` / `--allow-env-conflict`，该豁免只作用于本次调用并写审计。注册表未声明的主机行为不变。
- **`--remote` 名单扩到 13 条**。不在名单的命令带 `--remote` 直接 `exit=2`，不再静默写本地库。
- **`system status --remote` 只报运行事实**：`status` / `active_runs` / `paused_runs` / `uptime_seconds` / `store_type` / `warnings` / 服务端 `version`；`config_path` / `db_status` / `db_driver` / `db_location` / `db_path` 列在 `local_only` 里。`GetStatus` 只做认证、不做策略判定，proto 未加宽。
- **审计远程输出含亚秒**：`audit list` / `audit export` / `audit show` 的 `--json` 现在与本地一样保留纳秒（`TraceEntry.timestamp_nanos`）；`group list` 的 `--json` 两种模式逐字节相同（补 `created_at` / `created_at_nanos` / `tenant_id`）。
- **`audit list` / `audit export` 不再在 1000 行处静默截断**：服务端按 `auditStorePageSize` 走全量、精确 `total_size`；`stored_detail` 让导出打到入库原文而非投影。
- **漂移基线主键改为 `(host, name)`**：命名多版本，未点名时读 `default`。

## Known gaps

- **CodeQL 有一条 high 未消警**：`internal/grpc/audit_service.go:261` 的 `go/uncontrolled-allocation-size`。qoder 在 CHANGELOG 中给出三条依据判为假阳性（`pageSize` 已夹在 `maxPageSize=1000`；master 上 #5/#6 是同形既有告警；CodeQL 不在必需门 `needs` 里），本版不动代码。master 上另有 6 条开放告警（含 critical `go/request-forgery`、high `go/sql-injection`），处置口径待仓库所有者统一定。
- **`--json` 精度仍是两档**：`template list` / `template show` / `target list` 的远程 `--json` 仍只到秒（文档如实标注）；`group list` / `audit *` 已到亚秒。把另三处补齐需要动 `pb.Template` / `pb.Target` 与三处已成文契约，不在本版。
- **写侧强制的作用面 = 注册表覆盖率**：`target-ownership.yaml` 未声明的主机继续按 labels/默认 env；存量冲突行的普查不在本版，启动时的冲突 WARN 保留。
