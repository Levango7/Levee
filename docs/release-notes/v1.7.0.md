# Release Notes — v1.7.0 (Phase B: AI 建议 + 对话引擎)

**发布日期**: 2026-08-16

## 概述

Phase B 为 LEVEE 引入了 AI 驱动的修复建议引擎和多轮对话能力，实现从告警→诊断→建议→审核→执行的智能运维闭环。

## 新特性

### B1: 知识库框架 + 历史故障匹配

- `internal/recommend/types.go`：定义 `HistoricalIncident`/`Runbook`/`FixPattern`/`Match`/`RiskLevel` 核心数据结构
- `internal/recommend/knowledge_base.go`：`KnowledgeBase` 存储与 `Match` 匹配算法，采用 Jaccard 相似度 + 症状匹配 + 根因匹配三维加权评分
- `internal/recommend/defaults.go`：内置示例知识库数据，开箱即用

### B2: LLM 集成

- `internal/recommend/llm.go`：`LLMClient` 接口 + OpenAI/Ollama adapter + `MockLLMClient`（用于测试与离线场景）
- `internal/recommend/sanitizer.go`：消息脱敏模块，内置 8 条规则（IP/密码/API key/DB 连接串/JWT/AWS access key/邮箱/手机号），防止敏感信息外泄到 LLM

### B3: 修复方案生成

- `internal/recommend/engine.go`：`RecommendEngine` 集成知识库 + LLM + 脱敏 + 优雅降级（LLM 不可用时回退到知识库匹配）
- `internal/recommend/workflow_gen.go`：`WorkflowGenerator` 将修复方案转换为 LEVEELang YAML 草稿，可直接导入执行

### B4: 对话引擎 + 会话管理

- `internal/conversation/session.go`：`Session`/`SessionState`/`Message`/`Reply`/`Action` 数据模型，支持会话持久化与恢复
- `internal/conversation/engine.go`：`ConversationEngine` 多轮对话状态机，状态流转 `Idle→Diagnosing→Recommending→Reviewing→Executing→Done/Failed`，集成诊断引擎与建议引擎

### B5: IM 机器人对话扩展

- `internal/conversation/im_adapter.go`：`IMAdapter` 桥接 ChatOps（飞书/钉钉/Slack）→ `ConversationEngine`，支持审批卡片交互与命令路由

### B6: Web UI 对话框

- `internal/conversation/web_hub.go`：WebSocket `Hub` + `WSClient` 实时对话通道，`WSRequest`/`WSResponse` JSON 协议，支持多客户端广播与会话隔离

### B7: CLI 对话命令

- `cmd/levee/cmd_converse.go`：`levee converse` 命令，支持单次消息模式与交互模式，交互模式内置命令 `/help` `/state` `/history` `/sessions` `/new`

## 使用示例

### CLI 对话

```bash
# 单次消息
levee converse "web-01 CPU 使用率过高"

# 交互模式
levee converse --interactive

# 从告警创建会话
levee converse --alert alert-123 --interactive
```

### 交互模式内置命令

| 命令 | 说明 |
|------|------|
| `/help` | 显示帮助信息 |
| `/state` | 查看当前会话状态 |
| `/history` | 查看当前会话消息历史 |
| `/sessions` | 列出所有会话 |
| `/new` | 创建新会话 |
