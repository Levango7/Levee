## 怎么读这份文档

四层分法：

- **代码层**：引擎/治理链自身的正确性和能力。这是所有 UI 的地基，除非说明，否则先修这里。
- **可视化层**：把已有能力用 UI 暴露给不同角色。任何一层都必须先被**代码层**证实可用，`ui-blueprint.md` 中的界面不能编造 API。
- **交互层**：操作路径的闭环，包括向导、空状态、错误恢复。
- **运营层**：面向未开发者（controller、值班），不是写给开源用户。
