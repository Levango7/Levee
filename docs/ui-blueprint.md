## 1. 信息架构

**主导航（左侧 Sidebar，220px/收起 64px）**

```
变更看板   /changes       ← 默认首页：全量变更的生命周期视图
审批中心   /approval      ← 待审批列表（未结案的 draft/pending）
实时监控   /monitor       ← 执行进度、批次、门禁
集群拓扑   /cluster       ← 集群节点、任务分配、故障接管
AI 对话   /conversation   ← 告警→诊断→建议→变更闭环
模板管理   /templates     ← 可复用定义（输入参数表单）
目标机     /targets       ← 主机清单与冻结状态
审计查询   /audit         ← 证据链 / hash 链
系统状态   /system        ← 版本、doctor、配置
```

**独立链路（不进 Sidebar）**：`/login`、`/login/callback`、`/m/...`（移动审批深链）、`NotFound`。

## 3. 关键交互流

### 3.1 批准闭环（最小操作路径）

```
审批人
  ↓ /approval（只看到真正 pending 的）
  ↓ 打开卡片 → 详情页：计划哈希 + 影响面 + 回滚声明 + 门禁 + 风险评分
  ↓ [批准] / [否决]
  ↓ 状态机门禁守卫：只接 draft→approved / pending→approved
  ↓ audit 行持久化（含 plan_hash 绑定）
```

### 3.2 部分回滚的补救闭环（本系统最有辨识度的交互）

```
值班运维
  ↓ /changes 看到 [部分回滚]（警戒色）
  ↓ 打开详情页 → 自动聚焦「批次 3/3 web-7」
  ↓ 干预区显示三条凭证：失败原因、已补偿的证据、未补偿的缺口
  ↓ 选项：
     [ 一键补残余补偿 ]    ← 调用 RollbackChange（只补缺口，不重复已成功的）
     [ 人工修复完成标记 ]  ← 手工处置后归档
     [ 查看 web-7 执行日志 ]
  ↓ 结果：rolled_back_partial → rolled_back 或停留在 partial（诚实）
```

### 3.3 AI 闭环（接通尚未完成的桥）

```
告警/提问
  ↓ /conversation 诊断 → 建议 → 生成草稿（合法 LEVEELang）
  ↓ 用户"确认"
  ↓ 「一键生成变更并提交审批」    ← 当前缺失，roadmap P1
  ↓ 草稿 → CreateChange → PlanChange → 审批
  ↓ 批准 → ApplyChange → 门禁 → 回滚/完成
```

## 4. 视觉与交互规范

**状态色板**（必须与 ``web/src/utils/format.ts`` 的 ``STATUS_COLOR`` / ``STATUS_LABEL`` 一致，改这里必须同步 ``runstatus``）：

| 状态 | 色 | 含义 |
| --- | --- | --- |
| draft / planned / pending | info | 未启动 |
| approved | success | 就绪 |
| running | primary | 执行中 |
| paused | warning | 已挂起 |
| completed / rolled_back | success | 正常收敛 |
| rolled_back_partial | warning | **未完全恢复** |
| rollback_incomplete | danger | **未完成恢复** |
| failed / rejected / cancelled / interrupted | danger | 失败家族 |
| archived | info | 历史 |

**约束**：

- ``partial_rollback`` 与 ``rolled_back`` **不得同色系**，前者永远用警示色——这是 D-2 的核心意图（不能让"没恢复"看上去像"已回滚"）。
- 所有"步进器/时间线"用同一种形状（``●──◐──○``），风险色 = ``partial``，错误色 = ``incomplete``，中性色 = ``completed``。
- 密度：表格行高 36px，±12px 间隙；间距基数 4px。
- 所有列表必须有"空状态"文案（不能只是空白）——此前 ``pending_approval`` 死键让待审批页长期表现为空白。
- 键盘可达：Tab 顺序 = 徽章 → 筛选 → 表格 → 操作按钮；Enter/Space 激活。
